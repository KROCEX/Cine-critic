### 修复账号系统登录 500 错误：next-auth v5 beta → v4 回退

**问题根因：** next-auth v5.0.0-beta.32 与 Next.js 16 + Turbopack 存在深度不兼容：
- `Function.prototype.apply was called on #<Object>` — Turbopack 对 v5 配置对象的模块打包异常
- `satisfies NextAuthConfig` 移除后问题依旧，说明是框架层面的兼容性问题

**修复措施：**
- 降级到 `next-auth@4` 稳定版（移除 @auth/mongodb-adapter）
- 重写 `lib/auth.ts`：使用 `NextAuthOptions` 类型，简化 callback 类型断言
- 重写 `middleware.ts`：使用 v4 的 `withAuth` + `nextauth.token`
- 更新 `app/api/auth/[...nextauth]/route.ts` 和 `app/api/admin/ratings/route.ts` 引用 `authOptions`

**验证结果（修复后）：**
- 所有 8 个核心端点 → HTTP 200 ✅
- 注册 API: POST → success:true ✅
- /admin/ratings → 正确重定向到登录页 ✅
