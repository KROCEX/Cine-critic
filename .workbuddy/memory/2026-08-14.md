### 实现完整片单功能（参照网易云音乐歌单）

**数据模型：**
- `models/Playlist.ts` - userId/title(≤30)/description(≤100)/tags[]/isPublic/movies[]/likes/时间戳

**API 路由（10 个接口，6 文件）：**
- `app/api/playlists/route.ts` - POST 创建（登录 + 校验）
- `app/api/playlists/my/route.ts` - GET 我的片单
- `app/api/playlists/explore/route.ts` - GET 广场（公开 + likes 降序 + 分页 + populate 创建者）
- `app/api/playlists/[id]/route.ts` - GET 详情（私有鉴权）/ PUT 更新 / DELETE 删除
- `app/api/playlists/[id]/movies/route.ts` - POST 添加（TMDB ID 校验 + 去重）/ DELETE 移除
- `app/api/playlists/[id]/like/route.ts` - POST 收藏 / DELETE 取消（防负数）

**前端页面：**
- `app/playlists/my/page.tsx` - 我的片单管理（卡片网格 + 新建/编辑/删除）
- `app/playlists/[id]/page.tsx` - 详情页（信息 + 电影网格 + 添加/移除 + 收藏）
- `app/playlists/explore/page.tsx` - 广场（分页）
- `app/profile/page.tsx` - 个人主页（公开片单区域）

**组件：**
- `components/PlaylistCard.tsx` - 片单卡片（含 actions 插槽）
- `components/PlaylistModal.tsx` - 新建/编辑弹窗（标签预设 + 自定义 + 公开切换）

**辅助/扩展：**
- `lib/get-current-user.ts` - 服务端获取当前 userId
- `lib/playlist-serialize.ts` - Playlist 序列化
- `lib/playlist-tags.ts` - 标签预设（类型/年代/其他）
- `types/playlist.ts` - 前端共享类型
- `lib/tmdb.ts` - 新增 searchMovies / fetchMoviesByIds
- `app/api/tmdb/search` + `app/api/tmdb/movies` - 搜索/批量电影信息
- `components/Sidebar.tsx` - 片单入口 + 展开列表 + 新建快捷按钮

**修复（历史遗留 + 环境）：**
- `lib/db.ts` - 修复 mongoose 缓存类型错误（改用显式类型断言），新增 dns.setServers 公共 DNS

- TypeScript 类型检查通过（0 错误），所有页面路由 200
