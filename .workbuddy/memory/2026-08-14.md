### 实现完整片单功能（参照网易云音乐歌单）

**数据模型：**
- `models/Playlist.ts` - userId/title(≤30)/description(≤100)/tags[]/isPublic/movies[]/likes/时间戳

**API 路由（10 个接口，6 文件）：**
- `app/api/playlists/route.ts` - POST 创建（登录 + 校验）
- `app/api/playlists/my/route.ts` - GET 我的片单
- `app/api/playlists/explore/route.ts` - GET 广场（公开 + likes 降序 + 分页 + populate 创建者）
- `app/api/playlists/[id]/route.ts` - GET 详情（私有鉴权）/ PUT 更新 / DELETE 删除

- `app/api/playlists/[id]/like/route.ts` - POST 收藏 / DELETE 取消（防负数）
